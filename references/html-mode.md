# HTML 模式：HTML＋SVG 分页渲染为图片

正文统一用本流程生成小红书 PNG，包括选择生图模式时的正文。HTML 排版连续段落与公式，HTML 模式的非正文视觉再用 SVG 绘制；逐页输出固定画幅 PNG。HTML、SVG 和 Markdown 保留为制作源文件。

先按[图文组织规则](content-plan.md)整理连续正文与辅助解释图。正文应能在图片里独立读完；精简冗余不等于压成短句提纲。只有明确要求一图流时才按总览组织，而非把整篇文章默认缩成一张图。

## 页面与排版

- 默认 `academic`，浅暖米色底 `#F7F4ED`、蓝橙强调、轻量线条，不进行主题比较。封面、正文和辅助图背景统一，普通容器与 SVG 留白区域沿用页面底色，避免残留纯白色块。每页固定 1080×1440 CSS px，默认 DPR 2 输出 2160×2880 PNG。页面外的留白、预览导航不进入图片。
- 每页承载一个完整解释目标。图与对应标签、条件同页；按需使用有直接关系的局部分栏，不强制等宽等高。辅助解释图给核心关系留出主要面积，不添加推导侧栏或总结条。
- 正文采用清晰的连续段落和克制标题，允许纯文字页；不默认做成巨幅标题、口号或零散要点卡。容量不足时保留连贯解释并增页，在完整段落或推导边界拆分，不缩字、不拉长画布。
- 中文默认 Microsoft YaHei，数学用 KaTeX 配套字体，代码等宽。用户参考图默认只用于字号、行距、段落间距和留白，不跟随更换字体，也不复制账号标识、手机状态栏或阅读器界面。
- 在 1080×1440 CSS px 下，正文可从 38–40px、行高 1.35–1.45、段落间距 28–40px、左右留白约 72–84px 起步；标题约 44–48px，图注和标签至少约 26px。这些是排版起点，按参考图与约 390px 宽的实际预览调整；DPR 不增加内容容量。SVG 标签按最终显示尺寸核对。
- 标题、段落、公式和图形对齐。普通文字左对齐，容器只用于有意义的分组。不能依靠悬停、展开、动画或滚动条理解最终静态图片。

## 公式

使用本地 KaTeX；行内公式用 `\(...\)`，独立公式用 `$$...$$`。HTML 内保留可靠的数学排版，最终随页面渲染为 PNG。准确保留被选入图面的变量、公式含义和必要条件。

定义靠近首次引入文字，推导靠近解释，核心结果独立成行。正文页保留主线所需的公式与连续推导，辅助图只保留与几何关系直接对应的公式。长公式合理断行，必要时另设正文页，不整体缩小或使用公式内滚动条。

公式默认无底色和边框；只有确需强调的完整公式或核心结果才考虑克制浅底。首次出现、长、复杂、独立成行或 boxed 都不是充分理由。带底公式占整行，重复引用默认不再强调。主体墨灰，关键项按解释关系着色，与图中对象保持一致。

## SVG 制图

围绕稿件和共同选点规划绘图，采用能准确表达关系的最小构造。静态几何优先 TikZ 转 SVG 或 Typst＋CeTZ；简单图形、既有 SVG 修改可以直接编辑 SVG。实验数据可用 ECharts 的 SVG 渲染器，特殊映射按需用 D3，流程按需要选择布局工具。无需为静态配图添加交互依赖。

工具不可用时选择质量可靠的等价构造，不用粗糙手画冒充完成。库的字体、线宽、箭头和颜色应与图文一致。先明确几何坐标、投影及尺度，再制作图形；参考本地向量和对应比较示例，但不照搬全部布局和文字。

用户提供的技术示意图先查看，默认按原图重建为真正 SVG：保留内容、构图、对象关系、顺序、配色和风格，可以修正生成瑕疵，不能改变含义。无法辨认处结合稿件核实，仍不确定则指出，不猜测。

不能把 PNG 包进 SVG 的 `image` 标签或 base64 就声称完成矢量转换，也不默认整图自动描摹。保留原图与制图源文件，实际渲染后对照。重建不合格时说明具体差异；只有用户明确要求改用原图时才直接嵌入。照片等不适合矢量重建的材料保留原始图像。

SVG 使用 `viewBox`。数学标签采用可靠工具生成的矢量文字，或置于 `.figure-scene` 中的 `.figure-label` HTML 层，由 KaTeX 排版；不要把 LaTeX 原文塞进 SVG `text`。图形 CSS 只作用于自有 SVG，不覆盖 KaTeX 内部图元。

## 渲染与交付

先编写连贯的正文渲染稿，保留原始稿件。按计划组织独立页面；每页可使用独立 Markdown，避免自动切句破坏段落或图意。`---` 在现有渲染器中只是分隔线，不是手动页界。两套模式比较时，正文只渲染一次并复用相同 PNG 和对应 HTML 资源。

在技能根目录运行：

```bash
python -X utf8 scripts/rednote_render.py cards.md --math katex --save-html -o "<artifact_dir>"
```

默认得到 `cover.png`（稿件含封面标题时）、`card_1.png` 等；`--save-html` 同时在 `html/` 保留页面源文件和本地数学资源。无需额外封面时不设封面 front matter，首张内容页可直接作为第一张图。`--format html` 仅用于单独检查中间源文件，不能代替本模式的 PNG 交付。

图片路径相对于渲染稿目录解析。加载本地字体和数学资源后按页面截图；不能把一张长网页机械截断为几张不完整的图。超出画幅时脚本报错，重新组织图文后再生成，不裁内容或输出超长图片。

查看所有实际 PNG，核对尺寸、公式、几何、标签、遮挡、页界和手机尺寸可读性。修改后重新截图并检查。HTML 页面预览只辅助定位问题，最终验收以图片为准，不要求测试投影、目录跳转或浏览器原生缩放。

按阅读顺序交付 PNG，标题和配文与图片放在同一成品目录，目录汇总按[工作区规则](workspace.md)执行；来源与插入位置另记交付说明，保留 Markdown、HTML、SVG 及必要制图源文件。未输出图片时不能标记完成。
