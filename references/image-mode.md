# 生图模式：正文用 HTML，非正文视觉用 ImageGen

整篇博客的正文页先按 [HTML 流程](html-mode.md)排版为 PNG；ImageGen 只制作辅助解释图及用户明确要求的其他非正文视觉。先按[图文组织规则](content-plan.md)确定完整页序，将生成的辅助图插入 HTML 正文页之间。“生图模式”不意味着把长段正文交给图像模型。

## 图形与视觉

遵守技能入口的科学几何规则和配色，按内容选择向量、几何分解、轨迹与边界、对应比较、流程或简化曲线。球面或三维约束用少量浅灰线框提示，主要向量、三角形和标记承担解释，不用实体质感、密集网格或复杂光照。

默认使用浅暖米色背景 `#F7F4ED`，不用纯白底；精确的矢量式线条、严格对齐和合理留白。容器只用于有意义的分组，沿用页面底色与细框，浅填充突出区域。字体、箭头、线宽、标签和颜色在同组图片中一致。

自然语言默认简体中文，保留必要专名和缩写。中文优先思源宋体、Noto Serif CJK SC 或相近现代宋体／明朝体；英文采用 STIX、Latin Modern 或 Times-like serif。数学标签按标准 LaTeX 记号提供，核对上下标、希腊字母、分式、向量和范数；不能因 prompt 写了 LaTeX 就认为生成结果已正确排版。

最终统一为 3:4 竖幅，目标至少 1080×1440。prompt 明确比例、留白、安全边距和清楚的大字；内容少时放大核心关系，不为填满画布加说明。横向偏好只适用于图中局部布局。

## 生图执行

每张图先整理已经核实的图面说明：

```text
制作模式：生图；图像类型：辅助解释图／明确要求的一图流或其他非正文视觉
主题与对应原文位置：
本图要看懂的一个问题（或总览主线）：
核实的对象、关系和必要条件：
准确上图文案、变量和公式：
构图、阅读顺序和对象颜色映射：
输出：3:4 竖幅，高分辨率，浅暖米色背景 #F7F4ED（不用纯白底），手机阅读时标签清晰
本图不纳入的解释及其 HTML 正文页位置：
```

将说明和相应类型约束交给可用图像生成工具，直接生成图片。当前环境提供 `image_gen` 时使用该工具；有适用的图像生成技能时遵循其调用和交付方法。不能用 HTML 截图冒充模型生图，也不默认制作 SVG。“矢量式”描述视觉效果，只有用户明确要可编辑矢量文件时才另做 SVG 并实际渲染检查。

参考图片先查看，再通过工具的图片输入保持对象关系和风格。经核对的生成图片可作为同组后续图的风格参考，不能替代每张图的事实说明。

工具不能精确指定 3:4 时，在生成要求中预留边缘并检查实际尺寸。比例不对优先要求工具修改构图；必要时可等比缩放并补与背景一致的浅暖米色边缘到 3:4（工具／用户允许时），不能拉伸图形或裁掉内容。不能因 prompt 写了比例就声称实际比例合格。

工具暂不可用时说明限制并保留图面说明；不将未生成的图片描述为完成，不静默改用 SVG 或网页截图。

## 检查与交付

查看每张实际图片，核对文案、缩写、变量、上下标、公式、几何关系、前后状态、标签遮挡和裁切；检查实际尺寸为 3:4。有错误时修正并重新查看。

在手机大小预览中检查可读性。拥挤时先删重复解释、缩短标签或减少非必要元素；需拆图时按完整关系拆，并尊重用户指定数量。不能靠放大原图才能读懂基本标签。

把 HTML 正文图片与实际生图结果按共同页序交付，记录每页的类型和制作方式；不强制额外封面。发布配文只作摘要，保留正文排版稿、提示词、参考图和图面说明。比较两套时直接复用同一套 HTML 正文页，只替换非正文视觉，不能将 HTML 截图冒充生图结果。
