# 生图模式：正文用 HTML，概念辅助图用 ImageGen

整篇博客的正文页按 [HTML 流程](html-mode.md)排版为 PNG；ImageGen 制作辅助解释图及用户要求的其他非正文视觉。先按[图文组织规则](content-plan.md)确定页序，将图放在理解障碍处；不把长段正文交给图像模型。

## 按解释任务划定精度边界

ImageGen 可表达概念直觉、机制、前后变化、整体关系与方法对照，简单几何也必须与解释一致。当结论依赖严格投影、垂直、切线、等长、共享端点、精确数量或数值比例时，按技能入口将该关系交给精确绘图环节；真实实验曲线使用原图或真实数据。不能用“示意”掩盖关键关系错误，也不把 SVG 截图再生图就视为保留了数学保证。

已有好图优先复用；用户要优化生图时保留有效构图，重点改善配色、字号、线条与留白。参考图只能辅助构图和风格，最终图仍需检查。用户只允许 ImageGen 时如实交代无法验证的精确关系，不静默改成交付代码图。

## 图形与视觉

按[语义配色规范](visual-system.md)使用浅米色 `#FAF9F5`、暖深灰与少量学术蓝；默认一种强调色，必要对照最多两种。不要添加纸纹、噪点、仿旧滤镜、密集网格或立体光照。用位置、方向、连接、前后变化承担解释，不把所有图套成彩色框加箭头。

自然语言默认简体中文，保留必要专名和缩写。沿用项目生图字体：中文优先思源宋体、Noto Serif CJK SC 或相近现代宋体；英文采用 STIX、Latin Modern 或 Times-like serif。只放短标签与少量直接相关公式，长公式和复杂局部着色交给正文排版。数学符号按标准记号提供，不因 prompt 写了 LaTeX 就认为输出正确。

最终使用 **3:4 竖幅**，目标至少 1080×1440。竖幅不是让所有关系垂直排列：局部对比可横向，主阅读顺序按图意安排。内容少时放大核心关系，内容多时减少重复或按完整关系拆图，不为填满画布加总结卡片。标签在手机尺寸下清楚，正文位置、来源、页序等制作信息不画进图里。

## 从图面说明到实际 prompt

工作稿先记录：对应原文位置、本图回答的问题、核实的对象与条件、精度判断、上图文字白名单、语义颜色映射、相邻正文承接位置。整理完直接制作，不把这张内部表单当作等用户批准的关卡。

给图像模型的 prompt 只描述最终画面，**不包含“使用 SVG / HTML / CSS / TikZ”、源码、像素坐标或正文页路径**。从工作稿中提取必要内容，并展开具体色值与映射；不能把下面的待填项原样发给工具。

```text
生成一张用于小红书技术阅读的辅助解释图：[本图只需看懂的问题]。
画幅：3:4 竖幅，高分辨率；大字短标签、清晰线条，边缘留出安全空间。

【允许出现在图上的文字】
短标题：[准确标题]
标签：[逐项列出短标签]
公式：[少量与画面直接对应的公式；无需公式时删去此项]
必要条件：[只有理解画面不可缺少的条件]
仅绘制以上文字；不画后续指令的标题、色号、尺寸或制作说明。

【画面说明，不作为文字绘制】
核心对象与关系：[已核实的机制、方向与前后变化]
构图与阅读顺序：[用自然语言说明空间关系，避免像素坐标]
主体占主要面积；用图形表达关系，长推导与完整解释留在正文。

【颜色与线条，不作为文字绘制】
平面浅米色背景 #FAF9F5；普通文字和公式主体 #2F2D29；
次要文字 #6B675F；可辨参考线 #827C72；非关键边界 #DCD7CD。
重点对象 [名称及完整公式符号] 使用学术蓝 #3568B0，
其公式符号（含上下标）、标签、线段、箭头和端点保持同色。
[仅确有必要时加入：对照对象及完整符号使用橙色 #B85C2E，映射同上。]
其他对象保持中性，通过标签、位置和线型区分；全图含子图最多两种强调色。
等号、加减号和括号保持暖深灰；不把整条公式染成蓝色。
不添加纸纹、泛黄、渐变、彩虹色、装饰图标、长侧栏或底部总结条。

【字体】
简体中文现代宋体风格；英文与数学符号为清楚的 serif 风格；短标签足够大。
```

一图流仅在用户明确要求时替换图像类型与问题为总览主线，允许必要分面与短说明；颜色预算仍覆盖整张图，不扩成每块一色。

## 生成、修正与交付

将具体 prompt 交给当前可用图像生成工具；有适用的生图技能时遵循其调用、展示和保存方法。“矢量式线条”只描述视觉效果，不意味着输出矢量代码。工具不可用时保留 prompt 并说明未生成，不用网页截图冒充。

参考图片先查看，再通过工具的图片输入保持对象关系与风格。已检查的生成图可作为同组风格参考，不能替代每张图的事实说明。首轮有错误时优先指出具体错误；若关键构图在局部编辑后仍错误，改写图面说明并重新生成，不无限复用错误图。

检查实际输出的文案、对象数量、箭头方向、完整符号、公式、颜色对应、遮挡与裁切，以及真实像素尺寸。比例不对时请求工具修正构图，不能拉伸或裁掉内容；遵循当前工具对图片编辑的限制，不自行用脚本修改生成图。记录实际尺寸与目标是否一致，不能仅凭 prompt 声称符合 3:4 或精确 HEX。

在约 390px 宽的手机预览中检查可读性。拥挤时删重复解释、缩短标签或减少非必要元素；拆图按完整关系进行，尊重指定数量。未验证的核心关系不能作为合格成品。

整篇交付时把正文图片和辅助图按页序汇总，记录各页实际制作方式。保留工作稿与实际 prompt，来源在配套说明中注明；只请求辅助图时不扩成整篇。需要将生成图放入整篇博客交付目录时，按当前工具允许的文件输出流程处理；仅为展示已返回的生成图不重复下载或另做副本。
