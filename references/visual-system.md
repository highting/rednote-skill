# 语义配色：暖纸底、少色、公式与图形对应

HTML 与 ImageGen 共用此规范。它是本项目的自定义配色，借鉴论文插图的用色逻辑，不称为任何会议的官方色卡。沿用当前博客已明确的对象映射；用户指定其他风格时按其要求调整。

## 固定色板与颜色预算

| 用途 | 色值 | 使用条件 |
|---|---|---|
| 主背景 | `#FAF9F5` | 封面、正文、辅助图和普通容器统一，干净平面浅米色 |
| 次级分区 | `#F3F1E9` | 必要的局部分组、代码底色或预览外部留白 |
| 正文、公式主体、主要中性对象 | `#2F2D29` | 大多数文字和非强调对象 |
| 次要文字 | `#6B675F` | 图注、页码、次要说明 |
| 可辨认的参考线 | `#827C72` | 参考向量、坐标轴、必要约束标记 |
| 非关键辅助线、边界 | `#DCD7CD` | 分隔线、非核心空间轮廓；不承载关键文字 |
| 主强调 | `#3568B0` | 本图选定的重点对象或关键路径 |
| 必要对照 | `#B85C2E` | 确实需要第二组重点对象时才启用 |
| 小面积同色衬底 | `#E9EEF3` / `#F4E9E0` | 对应蓝／橙；不表示新类别，普通文字仍为暖深灰 |

默认一张自绘图只有一种强调色，最多两种；中性色与背景不计入。预算覆盖整张图的标题、公式、标签、图例、箭头和所有子图，不为每个子图重开色板。橙色不是常驻装饰色；多对象用直接标签、线型、点形、位置和分组区分。

主背景不加纸纹、噪点、仿旧、泛黄或全局滤镜。不要扩成棕黄灰绿的复古配色，不用大面积彩色模块、彩虹高亮、装饰性渐变或发光制造科技感。关键对象保持清晰，不整体降低透明度。

## 制图前固定语义映射

先选定颜色的主要用途：区分方法、突出分量，或标记路径。蓝色不能同时代表多个无关含义。工作稿记录下面的映射，成图不必额外画一张颜色表：

| 对象／完整符号 | 图形与标签 | 颜色 | 线型／位置 |
|---|---|---|---|
| 本图重点分量 | 对应线段、箭头、端点与短标签 | 主强调蓝 | 实线 |
| 可选对照对象 | 相同条件下的对照及其标签 | 对照橙 | 另用位置或点形区分 |
| 参考对象与普通公式 | 原向量、坐标轴、运算符 | 暖深灰或参考灰 | 有明确含义时用虚线 |

同一对象跨页保持同色，前后状态优先用上下标、虚实线和位置区分，不因“更新后”自动引入第三种色。普通正文提及不必每次着色。

## 公式与图形同色

公式默认暖深灰，只强调当前需要的一到两个完整语义单元。被强调的完整符号（包含向量标记和上下标）、图中标签、线段、箭头和端点同色。等号、加减号、括号及非重点变量保持中性，不把整条公式染成主题色。

例如解释垂直分量时，只让完整的 `u_t^⊥` 及其对应箭头为蓝色；原向量、平行分量、参考轴和运算符可保持灰色。是否增加橙色取决于是否真的需要突出第二个对象，不取决于公式有几个变量。该投影关系的精确绘制按 [HTML 流程](html-mode.md)完成。

HTML 中集中使用主题变量及语义类，公式局部着色可用 `\textcolor{#3568B0}{\mathbf{u}_t^{\perp}}`；变更映射时同时更新公式、SVG、标签和箭头 marker。类名 `updated` / `vector-update` 是兼容接口，默认改用参考灰；需要突出该状态时显式为对象指定 `primary` 或 `contrast`，不重新启用青色。容器的 `data-role` 只提供颜色变量，不会自动把所有子元素或 KaTeX 公式染色。

ImageGen 的实际 prompt 应展开所需色值与对象映射，不只写“学术风”“按统一色板”。HEX 是目标，不代表模型输出已经像素级校准。

## 证据与验收

原始实验图、照片和必须保真的材料保持原样，不为双色预算修改原图数据、图例或加滤镜；通过外部留白融入页面。依据真实数据重绘的连续量可使用带色标的单色渐变，必须有数值含义。

逐图核对颜色预算、完整符号与对象同色、箭头 marker 同色、辅助结构可辨认；去掉颜色后仍能靠标签与线型理解主要关系。在约 390px 宽预览中检查文字和线条；不要把写进 prompt 的目标当作已完成的检查。

规范来源：[用户分享的 Prompt 优化会话](https://chatgpt.com/share/6aa8d286-3d64-83ec-82ad-2aededcdab2d)，采用其中最后确认的暖米色方案；通用网页的横幅、字体及内容长度不覆盖本项目的小红书画幅和排版约定。
